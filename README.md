Pasos para ejecutar y usar esta herramienta:


1. Clona o descarga el repositorio en tu máquina ejecutando este comando:

```
git clone https://github.com/Doral-Ciberseguridad/Demo-Keylogger-Educativo-Python.git
```


2. Instala las dependencias necesarias de Python (como colorama y keyboard) ejecutando en tu terminal:

```
pip install colorama keyboard
```



3. Lanza el script de Python:

```
python Keylogger.py
```


4. Introduce la cantidad máxima de pulsaciones que deseas registrar en el teclado cuando el programa te lo solicite

<img width="782" height="540" alt="image" src="https://github.com/user-attachments/assets/662a6f71-23f5-45c4-a749-7805904b43a0" />



5. Introduce tu correo electrónico emisor, el receptor y la contraseña de aplicación correspondiente para automatizar la captura y exfiltración de los datos por correo electrónico

<img width="843" height="68" alt="image" src="https://github.com/user-attachments/assets/0e3e6117-125f-4cd8-8d41-3066ea159a49" />

Si has introducido bien los datos recibirás un correo electrónico con las teclas pulsadas por el usuario.
